# Wubbys-World

## Approved art standards

- [Graphics Production Standard](GRAPHICS_PIPELINE.md) — locked workflow for all new terrain and transparent object sprites, including alpha-edge verification, prototype testing, and approval.
- [Terrain Art Standard](TERRAIN_ART_STANDARD.md) — authoritative 112 × 57 isometric individual-tile method for all ground materials.

Changes to game art should follow these standards and preserve previously approved rendering and gameplay behavior.
